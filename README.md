# Modern Portfolio

This is a static portfolio website. If you see `localhost refused to connect`, it means the site is not currently being served.

## Run locally

1. Install Node.js 14 or newer.
2. Open a terminal in the repository root.
3. Run:

```bash
npm start
```

4. Open `http://localhost:3000` in your browser.

## Alternative

Open `index.html` directly in your browser if you do not want to run a local server.
